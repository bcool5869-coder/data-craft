# Free Data Science & AI courses: research notes (2026-09-19)

Everything below is free to learn from. "Cert" = whether a certificate is also free.

## 1. Foundations: Python, math, stats, SQL
| Course | Provider | Link | Level | Notes |
|---|---|---|---|---|
| CS50's Intro to Programming with Python | Harvard | https://cs50.harvard.edu/python | Beginner | Best free Python start; free CS50 cert |
| Essence of Linear Algebra / Calculus | 3Blue1Brown | https://www.3blue1brown.com | Beginner | Visual intuition, ~3 h each |
| Khan Academy: linear algebra, stats & probability | Khan Academy | https://www.khanacademy.org | Beginner | Exercises included |
| Mathematics for Machine Learning (book) | Deisenroth, Faisal, Ong | https://mml-book.github.io | Intermediate | Free PDF |
| Linear Algebra 18.06 | MIT OCW (Gilbert Strang) | https://ocw.mit.edu | Intermediate | Classic lectures |
| Think Stats (book) | Allen Downey | https://greenteapress.com/wp/think-stats-3e | Beginner | Stats with Python, free online |
| Intro to SQL / Advanced SQL | Kaggle Learn | https://www.kaggle.com/learn | Beginner | In-browser notebooks, free cert |
| SQLBolt, SQLZoo, Mode SQL tutorial | various | https://sqlbolt.com | Beginner | Interactive |

## Suggested learning path (what the site's curriculum follows)
1. Python (CS50P) → 2. Math intuition (3Blue1Brown, Khan) → 3. pandas/viz/SQL (Kaggle, VanderPlas)
→ 4. Statistics (Data 8, Think Stats) → 5. Classic ML (Google MLCC, ISLP, Kaggle) → 6. Deep learning (fast.ai, Karpathy, MIT 6.S191)
→ 7. LLMs & agents (Hugging Face LLM + Agents courses) → 8. MLOps & portfolio (Zoomcamps).
